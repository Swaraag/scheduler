One-time setup

1
Go to console.cloud.google.com, create a new project (name it anything).
2
Enable the Google Calendar API for your project (search it in the API library).
3
Go to APIs & Services → Credentials → Create Credentials → OAuth client ID. Choose Web application. Under "Authorized JavaScript origins" add your site URL (e.g. https://yourgithub.github.io). Copy the Client ID.
4
Get your Anthropic API key from console.anthropic.com.
