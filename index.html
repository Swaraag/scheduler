One-time setup

1
Go to console.cloud.google.com, create a new project, and enable the Google Calendar API.
2
Go to APIs & Services → Credentials → Create Credentials → OAuth client ID. Choose Web application. Add your site URL under "Authorized JavaScript origins". Copy the Client ID.
3
Get your Anthropic API key from console.anthropic.com.
